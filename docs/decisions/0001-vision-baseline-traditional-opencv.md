# ADR 0001：v1.0 采用传统 OpenCV 基线，不引入深度学习与深度传感器

- 状态：已接受（v1.0）
- 日期：2026-10（项目初期）

## 背景

项目目标是打通"感知 → 决策 → 控制"完整闭环。起步时可选路线：
传统计算机视觉（亮度阈值 + 形态学）或深度学习（语义分割 / 目标检测）；
传感器可选单目 RGB、深度相机或激光雷达。

## 决策

1. v1.0 只用传统 OpenCV 基线：单目 RGB → 亮度阈值 → 形态学 → 可通行掩膜
   → 左/中/右三分评分 → 滞回决策 → `/cmd_vel`。
2. v1.0 不加深度相机 / 激光雷达，保持依赖最小，接受单目无真实距离的限制。

## 理由

- 先打通链路，可解释、易调试：每一步输出（掩膜、评分、决策）都可直接可视化检查。
- 深度学习引入大量依赖与不可解释性，仿真内评估还存在域差距问题
  （后在 v2.0 步骤 13 评估中再次确认，见 ADR 0006）。
- 项目初期重心是学习 ROS 2 节点/话题/launch 机制，而非算法复杂度。

## 验证结果

- v1.0 闭环达成：机器人自主避障穿行障碍场地。
- v1.1 实测：相机 15Hz 发布，感知节点处理 15FPS 无积压，单帧处理 0.28~0.41ms，
  传统方案的性能余量非常充裕。
- 局限（已知并接受）：亮度阈值对光照/地面配色敏感，无真实距离，
  视觉盲区约 0.34m（v2.0 用雷达安全闸门补齐，见 ADR 0003）。

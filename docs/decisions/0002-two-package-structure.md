# ADR 0002：两包结构 + 感知决策控制安全一体化单节点

- 状态：已接受（v1.0），接口稳定后再拆分
- 日期：2026-10（项目初期）

## 背景

ROS 2 项目常见做法是把感知、决策、控制拆成多个节点/包。
但项目初期接口不稳定，多节点意味着大量的消息定义与进程间调试成本。

## 决策

只建两个包：

- `robot_description`：xacro 模型、world 场景、参数与地图、launch。
- `vision_perception`：感知 + 决策 + 控制 + 安全，一体化单节点
  （`perception_node.py`），内部计算拆成与 ROS 无关的纯函数。

## 理由

- 单节点串行便于定位问题：任何 bug 都在一个进程的调用栈里。
- 纯函数拆分保留了可测试性：掩膜、评分、滞回、融合等逻辑全部可用
  pytest 离线验证，无需启动仿真。
- 对外接口（订阅 `/camera/image_raw`、`/scan`，发布 `/cmd_vel`）保持稳定，
  未来要拆分时节点边界清晰。

## 验证结果

- 50 条 pytest 单元测试全部离线运行通过，覆盖全部决策纯函数。
- v2.0 融合改造（新增雷达输入）只动了节点内部，话题接口零变更，
  验证了"接口稳定后再拆"的判断。

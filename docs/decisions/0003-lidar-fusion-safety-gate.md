# ADR 0003：视觉 + 雷达融合采用安全闸门策略，闸门距离必须大于视觉盲区

- 状态：已接受（v2.0 步骤 10 + 绕行验证修复）
- 日期：2026-10-23

## 背景

v1.x 纯视觉方案有两个硬缺陷：

1. 相机装在 0.08m 高、ROI 只取图像底部 40%，产生约 0.34m 的视觉盲区
   ——贴得很近的障碍物视觉根本看不见。
2. 单目无真实距离，"可通行评分"是亮度启发式，不是几何测量。

2D 激光雷达能提供精确距离，问题是：怎么融合？

## 决策

采用**安全闸门**融合策略，而非加权平均：

- 雷达前方 60° 均分左/中/右三扇区（与相机 FOV 对齐），取各扇区最小距离。
- 某扇区 min_distance < `safety_distance` → 该方向评分强制归零（闸门关闭）。
- `safety_distance = 0.5m`，必须大于视觉盲区 0.34m（初版取 0.3m，被盲区击穿）。
- 新增 `side_guard_distance = 0.25m` 侧身护卫：直行时若侧方贴障则禁止继续直行
  （初版"中路畅通就直行"导致擦着障碍卡死）。
- 双看门狗：图像超时 1s 或雷达超时 1s 均触发安全停车；控制循环用独立
  定时器固定频率发布，不依赖图像回调。

## 理由

- 加权平均会让"很远但有少量读数"和"很近"混为一谈；闸门是布尔判定，
  行为可解释、可调参。
- 雷达负责"近处几何兜底"，视觉负责"远处可通行区域语义"，分工与各自
  物理能力匹配。

## 验证结果（detour_test.world，0.5m 方块挡在直行路径正中）

- (-2,0) 出发绕行方块抵达 (3.7,0)，全程零碰撞，车体与方块最小间隔 0.10m。
- 补齐双端滞回后 50 秒仅 4 次指令变化，无抽搐。
- 50 条单元测试全绿（含扇区映射、inf 过滤、闸门边界、看门狗）。

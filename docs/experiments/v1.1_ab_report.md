# v1.1 步骤8：三场景 A/B 对照实验记录

## 1. 目的

验证 v1.0 的亮度阈值基线（`gray_threshold=150`）在不同光照与地面配色下是否仍然可靠，
量化"感知算法 → 运动控制"整条链路的鲁棒性与性能。

## 2. 实验方法

| 项 | 说明 |
|---|---|
| 对照组 A（基线） | `obstacle_course.world`，光照 diffuse 0.8，地面 0.9 |
| 对照组 B1（弱光） | `dim_course.world`，仅光照 diffuse 降至 0.35 |
| 对照组 B2（低对比度） | `low_contrast_course.world`，仅地面材质降至 0.45 |
| 重复次数 | 每个场景 3 次，取平均值 |
| 单次时长 | 40 s（启动后稳定 12 s 再开始采集） |
| 场景布局 | 三场景障碍物、围墙、出生点完全一致（变量唯一性） |

采集脚本：[eval_session.py](file:///home/user/ros2_vision_obstacle_avoidance/tools/eval/eval_session.py)；
编排脚本：[run_ab.sh](file:///home/user/ros2_vision_obstacle_avoidance/tools/eval/run_ab.sh)；
原始数据：`docs/experiments/data/*.json`。

### 指标定义

- **FPS**：采集窗口内图像帧数 / 时长
- **处理耗时**：单帧 `imgmsg_to_cv2` + `compute_zone_scores` 的实际耗时（wall clock）
- **行驶距离**：`/odom` 累计里程
- **指令变化次数**：`/cmd_vel` 中 `angular.z` 变化超过 0.05 或"行进/停车"状态翻转的次数，衡量抽搐
- **停车占比**：下达零速指令的采样占比
- **最小可通行率**：三区可通行率在整个过程中的最小值（越低表示越接近误判边缘）
- **碰撞次数**：机器人中心进入障碍物 AABB 外扩范围（底盘 0.30×0.20）的次数

## 4. 结论

1. **三种光照/配色下行为一致**：9 次运行全部零碰撞，终点位姿几乎相同（x≈3.67，墙前 0.18 m 处停车），
   说明感知判定未因光照衰减或低对比度而发生误判。
2. **emissive 自发光是鲁棒性的关键**：弱光场景地面材质不变、仅光源减半，若无 `emissive`，
   地面灰度会跌进障碍物区间；实测该防护有效（步骤6 实测地面灰度 168，阈值 150，余量 18）。
3. **性能余量充足**：三个场景 FPS 均为 15.0（与相机发布率一致，无积压），单帧处理 0.28~0.41 ms，
   远低于 100 ms 控制周期。
4. **低对比度场景处理耗时略高（0.41 ms vs 0.28 ms）**：图像噪声更均匀，阈值分割后的连通域统计
   开销略增，但仍在微秒—毫秒级，不构成瓶颈。

## 5. 局限与后续

1. **场景区分度不足**：机器人沿 y=0 直线可直接抵达东墙，三个场景都没有真正触发绕行决策，
   因此本次 A/B 只能证明"不误判"，不能证明"绕行策略在恶劣光照下同样有效"。
   建议 v1.2 在 y≈0 的直线路径上增加障碍物，强制触发左右转向，再做对照组。
2. **仿真时钟延迟不可用**：Gazebo `/clock` 到达节点存在数十毫秒滞后，端到端延迟会出现负值，
   已按 0 处理；真实计算开销以"处理耗时"为准。
3. **碰撞判定为几何近似**：使用 AABB 外扩而非 Gazebo 接触传感器，边缘擦碰可能漏检。

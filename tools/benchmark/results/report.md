# OpenCV 反应式避障 vs Nav2 导航基准报告

指标定义见 `tools/benchmark/metrics.py`：

- 成功率：进入终点容差圆，或越过终点线且横向偏差 ≤ lane_tolerance（反应式臂不收敛到点，用后者）；
- 最小间距：所有雷达回波的最小值（越小越危险）；
- 碰撞：连续 2 帧出现 < 0.13m 回波记一次；
- 卡死占比：线速度 < 0.01m/s 的采样比例；
- 角速度 jerk：角速度二阶差分 RMS，衡量控制平滑度；
- CPU 占比：本次运行全部子进程（含 Gazebo 与启动阶段）累计 CPU 时间 / 墙钟时间（多核可 >1），用于比较整套栈的开销；

### 总体

| 臂 | 运行次数 | 成功率 | 场景平均到达时间(s) |
|---|---|---|---|
| 纯 OpenCV | 4 | 75% | 25.9 |
| 纯雷达 | 3 | 100% | 78.2 |
| 视觉+雷达 | 5 | 100% | 58.8 |
| Nav2 | 5 | 100% | 38.2 |
| Nav2+视觉护栏 | 3 | 100% | 46.9 |

### 自动结论

- 成功率（全部场景）：纯 OpenCV 75% vs Nav2 100%。
- 到达时间（仅共同场景 dim_course、low_contrast_course、obstacle_course）：纯 OpenCV 25.9s vs Nav2 25.1s，Nav2 更快。
- 路程差异来自路线策略：反应式臂边避障边绕行（无地图），Nav2 在已知地图上走接近最短路。
- 视觉+雷达融合成功率 100%，用于判断视觉与雷达是否互补。
- 视觉护栏叠加后成功率 100% → 100%，可直接看出 OpenCV 兜底是否有效。
- 视觉护栏开销（仅共同场景 detour_test、maze_course、obstacle_course）：Nav2 47.0s → 加护栏 46.9s。
- 视觉臂出现碰撞失败的场景：detour_test/vision。
